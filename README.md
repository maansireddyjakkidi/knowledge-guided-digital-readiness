# KG-MRL: Knowledge-guided multisource readiness learning

Reproducible **research software**, not a completed empirical study. Main-text outputs: **exactly two vector PDF figures and two CSV tables**. No fabricated empirical results.

## Installation and smoke test

```bash
pip install -r requirements.txt
python experiment.py --demo --out demo_results
```

Synthetic mode is **only a software smoke test and controlled simulation**. It is not evidence of firm-level prediction accuracy or model novelty.

## Real-data experiment

1. Download a legitimately accessible, documented firm-level dataset (candidate: [World Bank FAT survey](https://microdata.worldbank.org/collections/fat)). Observe its license, access restrictions, and citation requirements.
2. Construct a **measured and non-circular binary outcome**. A technology adoption indicator that is itself used among predictors **must not** be used as the target. Prefer subsequent adoption if longitudinal measurement exists; otherwise describe a cross-sectional proxy without calling it prospective readiness.
3. Harmonize features into a local CSV or Parquet file with the columns specified in `knowledge_rules.json`. The default configuration is a **placeholder schema**, not a verified mapping to any World Bank data release. Do not impute missing survey fields with made-up observations. Numeric variables and rule thresholds require documented harmonized units.
4. Edit `knowledge_rules.json` to define source-specific columns, outcome, group, and independently justified rules. Rule names and thresholds shipped here are **unvalidated hypotheses**, not established domain knowledge.
5. Run:

```bash
python experiment.py --data path/to/validated_firms.csv --config knowledge_rules.json --out real_results
```

## Outputs

- `Table_1_benchmark.csv`: out-of-fold discrimination, precision-recall, Brier score, ECE10, runtime.
- `Table_2_ablation_stress.csv`: 2x2 source-fusion × knowledge-rule ablation, plus missingness and noise stress tests.
- `Figure_1_architecture.pdf`: conceptual model and evaluation diagram.
- `Figure_2_results.pdf`: AUROC and missingness robustness.
- `out_of_fold_predictions.csv`, `bootstrap_intervals.csv`, `manifest.json`.

GroupKFold is used if a group column is present (e.g., country), otherwise stratified folds. Grouped folds may fail if class distribution is unsuitable; that failure is intentional. Imputation and encoding are fit only on training folds. Stress corruptions affect **test predictors only**, not the outcomes. Bootstrap intervals are descriptive and do not substitute for independent external validation. The knowledge model uses rule-derived predictors; it is **not yet a new constrained-optimization algorithm**, and any novelty claim requires literature comparison and stronger methodological development.

## Important limitations

No real dataset is bundled, no real-data performance is claimed, and no outcome definition or cross-country harmonization has been validated. Synthetic labels depend on constructed predictors. Survey weights, clustering, nested hyperparameter tuning, fairness, temporal validity, and external replication need study-specific decisions before journal submission. Do not publish restricted microdata. The software is a reproducible starting implementation, not a completed *Knowledge-Based Systems* experiment.


## Executed World Bank FAT feasibility benchmark

The separate `real_fat.py` script reproduces an **exploratory cross-sectional adoption** benchmark on the World Bank FAT 2019–2023 survey release. It does **not** establish prospective digital transformation readiness or a validated knowledge-guided advantage.

```bash
python real_fat.py --data WLD_2019-2023_FAT_v01_M_CSV.zip --out real_results
```

The FAT ZIP must be downloaded by an authorized user from the World Bank and stored locally; **raw firm microdata and prediction-level outputs are intentionally not committed**. The repository includes `results/Table_1_real_benchmark.csv`, `results/Table_2_real_ablation_stress.csv`, `results/paired_country_bootstrap.json`, and `results/manifest.json` from the executed experiment. Two PDF figures are regenerated by the script and are available in the separate downloadable research package.

- Observed outcome: `db11a5`, use of big-data analytics / machine learning in customer-related marketing, not future readiness.
- 19,736 analyzable establishments, 679 positive observations, 16 country/wave labels.
- Five-fold GroupKFold using the country label; median imputation is fitted on training folds.
- Full rule-feature model AUROC: 0.747355; multisource-only AUROC: 0.748095. Paired difference: -0.000740; country-bootstrap 95% interval [-0.002515, 0.001091].
- **No demonstrated AUROC improvement from knowledge features.** The knowledge interactions are hypotheses, not independently validated expert rules.
- Unweighted estimates; survey-design adjustment, country-wave sensitivity, construct validity, and independent rule validation remain open.
- `Table_2_real_ablation_stress.csv` averages fold-level metrics; it should not be directly interpreted as pooled out-of-fold AUROC.




## Manuscript-matched analysis (canonical)

The Knowledge-Based Systems Short Communication reports the matched-objective experiment in `validation_matched.py`. Capability-only, unconstrained multisource, and sign-constrained multisource models share the same ridge logistic loss, zero initialization, L-BFGS-B solver, and training-fold imputation/scaling. The only difference is nonnegative coefficient bounds on internet access and log computer count.

`validation.py` is retained for provenance. It still fits unconstrained models with scikit-learn LogisticRegression and the constrained model with L-BFGS-B, so those three scores are not a matched-objective ablation. Do not use `results/validation/` as the manuscript tables.

```bash
pip install -r requirements.txt
python validation_matched.py --data WLD_2019-2023_FAT_v01_M_CSV.zip --out matched_results
```

Download the FAT ZIP from the World Bank catalog; do not commit microdata. Aggregate outputs are in `results/matched/`. Vector figures: `figures/Figure_1_matched.pdf`, `figures/Figure_2_matched.pdf`.

| Model | Unweighted AUROC | AUPRC | Brier | Weighted AUROC |
|---|---:|---:|---:|---:|
| Capability | 0.6514 | 0.0670 | 0.03284 | 0.6115 |
| Fusion | 0.7523 | 0.1068 | 0.03229 | 0.6829 |
| Constrained | 0.7523 | 0.1068 | 0.03229 | 0.6829 |

Constrained minus fusion AUROC = 0. Both hypothesized coefficients were positive in all five folds, so the constraints were inactive. Weighted metrics use `base_wt` at evaluation only.

Group labels in the analyzable sample (16): Bangladesh, Brazil, BurkinaFaso, Cambodia, Chile, Croatia, Ethiopia, Georgia, Ghana, India, India_Wave2_New, Kenya, Korea, Poland, Senegal, Vietnam. Ethiopia has 0 positive `db11a5` outcomes, so leave-one-country-out metrics are reported for the other 15 labels. These strings are survey file labels, not a substitute for the official catalog citation.

## Expanded validation (2026-10-23): executed, not submission-ready

The older `validation.py` script is an unmatched-objective sensitivity study (provenance only):

```bash
pip install -r requirements.txt
python validation.py --data WLD_2019-2023_FAT_v01_M_CSV.zip --out validation_results
```

**Outputs:** `Table_1_validation.csv`, `Table_2_stress.csv`, `rule_diagnostics.csv`, `country_holdout.csv`, `validation_summary.json`, and exactly two vector PDF figures. Aggregated results are checked in under `results/validation/`; the two **current main-text SVG figures** in `figures/` were updated to show validation findings. Prior feasibility outputs in `results/` remain for provenance, not as the latest results.

**Observed dataset:** 19,736 FAT establishments, 679 positive `db11a5` outcomes; 16 country/wave labels. The outcome is observed marketing analytics adoption, **not prospective readiness**.

**Models:** capabilities-only logistic; multisource logistic; multisource logistic with nonnegative coefficients for internet connectivity and log computer count, optimized with bounded L-BFGS-B. The two constraints are **hypotheses**, not externally validated expert rules.

| Model | Unweighted AUROC | AUPRC | Brier | Weighted AUROC |
|---|---:|---:|---:|---:|
| Capability | 0.651292 | 0.066964 | 0.032838 | 0.611346 |
| Fusion | 0.752081 | 0.106681 | 0.032290 | 0.682587 |
| Constrained | 0.752273 | 0.106805 | 0.032287 | 0.682933 |

Paired constrained minus fusion AUROC: **+0.000192**, country-cluster bootstrap 95% interval **[-0.000096, +0.000425]**. The unconstrained model's two coefficients are positive in **every fold**, so the nonnegative constraints are **not binding**. Their satisfaction does not constitute a demonstrated knowledge-guided benefit; tiny score differences may reflect numerical optimizer differences.

Survey sampling weights are applied to *evaluation metrics only*, not model fitting. These estimates are **not** full complex-survey-design inference. LOCO results cover 15 country labels with both classes; one label has insufficient outcome variation. Fold-level stress results are means of fold metrics, not pooled OOF metrics. The code uses a fixed 2023 proxy for firm age; proper survey-wave harmonization is a further validation requirement. No nested tuning, external replication, prospective target, or independently substantiated knowledge rule is claimed. No original microdata or row-level predictions are committed.

**Interpretation:** multisource predictors are useful; this experiment provides **no persuasive evidence that knowledge constraints improve prediction or robustness**. Do not describe this as a confirmed novel KG-MRL method.
